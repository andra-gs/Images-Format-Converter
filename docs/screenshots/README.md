# README screenshots

Place screenshots in this directory using these filenames:

- `hero.png`: main application interface
- `file-queue.png`: selected files, previews, and file details
- `image-editor.png`: image editing workspace
- `export-settings.png`: optimization presets and Target Size controls
- `conversion-results.png`: output details and download actions
- `dark-theme.png`: application in dark theme
- `mobile-view.png`: responsive mobile layout

Use PNG where possible. Capture the real application and remove private filenames or personal information before committing screenshots.

The image blocks in the root README are commented out until the corresponding screenshots are added. Uncomment each block after uploading its image.
